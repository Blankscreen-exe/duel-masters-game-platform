# 0009. MIT license

- Status: Accepted
- Date: 2026-10-24

## Context

The repository is public and builds on MIT-licensed code (0002).

## Decision

This project's own code is MIT licensed. `THIRD_PARTY_NOTICES.md` keeps the notices of others'
material: the engine's MIT notice once its code is copied in, and the ownership notice for the
Duel Masters card pictures and text.

## Alternatives considered

- **AGPL-3.0**: would require anyone running a modified public copy to publish their changes.
- **No license**: the code would be visible but not reusable.

## Consequences

- Anyone may reuse the code, keeping the copyright notice.
- The card pictures and text are not covered by this license; they belong to Wizards of the Coast
  and Takara Tomy, as the notices state.
