Duel Masters - UI themes

Mockups of the same screens (lobby and game screen) in different styles. Switch between the lobby and the game screen with the buttons in the bottom right corner of each theme.

Card pictures load from the linked card database (resources/duelmasters_db), so open these files straight from disk in a clone made with --recurse-submodules. The game board itself is drawn by the duel board component; the mockups show how a theme frames and tints it. Battle Zone is the chosen theme (see design/SPEC.md, section 11); the others are rejected alternatives kept for reference.
